# CodeTask — Gerenciador de Tarefas

Aplicação web para gerenciamento de tarefas acadêmicas, desenvolvida com HTML5, CSS3 e JavaScript puro (ES6).

## Funcionalidades

- Cadastro de tarefas com título, disciplina, descrição, prazo, prioridade e status
- Listagem dinâmica de tarefas cadastradas
- Validação de formulário com JavaScript
- Navegação entre páginas

## Tecnologias

- HTML5 semântico
- CSS3 com Flexbox
- JavaScript ES6
- Vite

## Como executar

```bash
npm install
npm run dev
```

Acesse em: `http://localhost:5173`
